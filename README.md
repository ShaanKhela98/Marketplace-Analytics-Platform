# Marketplace Analytics Platform

## Overview

The Marketplace Analytics Platform is a synthetic ecommerce business intelligence and forecasting project designed to simulate real-world marketplace analytics workflows. The project combines SQL, Python, dashboard visualization, forecasting, and executive reporting into a single analytics portfolio case study.

This project was created to demonstrate practical skills commonly used in:

- Business Analytics
- Strategy & Operations
- Ecommerce Analytics
- Data Analytics
- Marketplace Intelligence
- Executive KPI Reporting

---

# Project Objectives

The goal of this project was to build an end-to-end analytics workflow capable of:

- Tracking marketplace KPIs
- Monitoring operational performance
- Analyzing customer purchasing behavior
- Evaluating seasonal trends
- Forecasting future marketplace revenue
- Creating executive dashboard reporting

# Database Design

The project uses a relational PostgreSQL schema centered around transactional marketplace sales data.

## Main Tables

- sales
- products
- categories
- customers
- customer_segments
- inventory
- calendar_factors
- search_trends
- competitor_benchmarks

The sales table acts as the primary fact table connected to operational and dimensional tables through foreign key relationships.

# Executive Dashboard Insights

## Revenue Performance

- Summer generated the strongest marketplace revenue performance.
- Beverage and snack categories consistently drove the highest GMV contribution.
- Monthly trends demonstrated realistic seasonal demand fluctuations.

## Customer Behavior

- Convenience Shopper customers generated the highest overall revenue contribution.
- Weekend purchasing activity showed stronger average transaction values.

## Operational Analytics

- Inventory demand increased significantly during summer periods.
- Search trend activity aligned closely with product demand spikes.
